# InfernoCMS

A CMS that gets out of your way — define content in code, get an API and admin UI instantly.

## Install

```bash
npm install infernocms
```

## Documentation

Full docs (config, API, fields, hooks, webhooks, deployment, etc.) live in the published package:

[packages/core/README.md](packages/core/README.md)

## Packages

| Package | Description |
|---------|-------------|
| [packages/core](packages/core) | Schema parser, database, API server, CLI, validation |
| [packages/admin](packages/admin) | Admin UI (Next.js 15 + shadcn/ui) |
